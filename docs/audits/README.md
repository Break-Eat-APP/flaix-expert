# Audits

Rapports d'audit du code et de la documentation (Codex ou autre), un fichier par audit : `AUDIT_AAAA-MM-JJ_<sujet>.md`.
Prompt à donner à l'auditeur : [`../developpement/CODEX_AUDIT_PROMPT.md`](../developpement/CODEX_AUDIT_PROMPT.md). Défauts classés P1 (avant la production), P2 (avant l'exploitation réelle), P3 (qualité, documentation), avec fichier et ligne.

Chaque défaut corrigé est noté dans le rapport (« corrigé le … , commit … ») : le rapport reste la trace de ce qui a été vu et de ce qui a été fait.
